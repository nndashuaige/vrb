# e16 2026-5-21

## 一、E16 实验设计思路

E16 是在 E15 的基础上新开的 reference 语义对照实验。

E15 的目标是尽量贴近论文里 “pre-interaction / humanless reference frame” 的描述，因此主 reference 使用了非常严格的：

- contact episode start 之前；
- 最近的 strict global no-hand frame；
- 连续 3 帧没有有效 hand bbox；
- 不使用 E14 clean reference 救回。

E15 的结果说明这个策略太硬：

- `subactions_success = 14/100`
- `ref_found = 27`
- `median reference_anchor_gap = 42`
- 主失败原因是 `no_strict_humanless_reference`

进一步诊断发现，很多样本并不是没有 pre-contact reference，而是画面里仍然有另一只手，或者 active hand 还在画面里但已经不适合用 `strict_global_no_hand` 判断。论文 3.2.1 的语义更接近：

> 找到 first contact timestep，把 contact point 和 post-contact hand trajectory 映射回 human 尚未进入交互区域的 reference frame；如果 human 一直在画面里但尚未交互，可以 crop out human。

因此 E16 不再把主 reference 限制为全局无人手，而是改成：

> 在 episode start 之前选择最近的 active hand 不可见帧。

这样可以检验论文语义是否更接近 `first-human-entry / active-hand-invisible reference`，而不是 E15 的 `strict global no-hand reference`。

## 二、E16 改了什么

E16 新增脚本：

```text
src/vrbreproduction/e16_active_hand_invisible_reference.py
```

正式输出目录：

```text
outputs/e16
```

Smoke 输出目录：

```text
outputs/e16_smoke10
```

E16 保留 E15 的主体结构：

- `video_id = P01_109`
- 前 100 个 EPIC annotations
- 一个 subaction 最多输出一个 final tuple
- 每个 subaction 只取第一个 new contact run
- candidate frame 固定为 episode start
- 不尝试 `t0+1/t0+2`
- Cell2 contact extraction / GMM 不改
- Cell3 homography + geometry gate 不改
- Cell4 heatmap generation 不改

E16 的核心改动只在 reference selection：

| 项目 | E15 | E16 |
| --- | --- | --- |
| 主 reference | strict global no-hand | active hand invisible |
| 是否要求全图无手 | 是 | 否 |
| 是否要求 3-frame no-hand streak | 是 | 否 |
| strict no-hand | 主筛选 | shadow diagnostics |
| E14 clean gate | 不用 | 不用 |
| object consistency / CoTracker | 不引入 | 不引入 |

E16 的 reference mode 为：

```text
active_hand_invisible_pre_contact
```

如果找不到 active hand 不可见帧，则失败：

```text
no_active_hand_invisible_reference
```

E16 相比 E15 明显改善：

| experiment | subactions_success | heatmap_pass | ref_found | strict_ref_found | homography_available | geometry_pass | median anchor gap |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

- reference 找到数从 `27` 提升到 `38`
- homography available 从 `16` 提升到 `29`
- final keep 从 `14` 提升到 `26`
- median anchor gap 从 `42` 降到 `13`

reference 更近以后，逐帧 homography 链明显更容易通过。

## 四、E16 真实漏斗

E16 的真实漏斗是：

| 阶段 | 剩余 |
| --- | ---: |
| 100 subactions | 100 |
| 有 new-contact candidate | 81 |
| Cell2 contact/GMM pass | 59 |
| reference found | 38 |
| homography available | 29 |
| final keep | 26 |

这个漏斗说明：E16 虽然改善了 reference selection，但仍然不可能达到 `80/100`。

最关键原因是：

> 在 reference 之前，Cell2 contact/GMM pass 已经只剩 59 个。

也就是说，即使 E16 后面的 reference、homography、geometry、heatmap 全部 100% 通过，当前 pipeline 的理论上限也只有 `59/100`。因此要达到 80，不可能只靠改 reference。

## 六、为什么 E16 仍然达不到论文级数据量

论文的数据准备更像大规模 data mining，不是严格的样本审计。

论文中比较明确的是：

- 对一个 video / clip 找 first contact timestep；
- 用 contact frame 的 hand-object 接触区域生成 contact point；
- 用 contact 后 hand bbox 位置生成 trajectory；
- 用 homography 映射回 reference frame；
- 如果 human 一直在画面里但还没有交互，可以 crop out human；
- 只有 human always in contact 才 discard。

而 E16 仍然比论文严格：

### 1. E16 把 EPIC annotation subaction 当作 sequence

E16 仍然假设：

> 一个 EPIC annotation subaction = 一个 training sequence。

但论文没有明确说 sequence 就是 EPIC annotation 里的 subaction。论文更像是：

```text
input video / clip -> first contact in that clip -> one tuple
```

因此 E16 的 `continuation_contact_run` 失败不一定符合论文语义。如果某个 annotation 开始时已经在接触，论文式 clip 可能会回溯到真正 first contact，或者根本不会把这个 annotation 当作独立 sequence。

### 2. E16 仍然要求 active hand 不可见

论文允许 human 一直在画面中但尚未交互时 crop out human。E16 没有做 crop-out，只要 active hand 在整个 360 帧窗口里一直可见，就失败。

在 E16 的 21 个 `no_active_hand_invisible_reference` 中，很多 search window 起点仍然检测到 active hand。它们可能需要的是论文式 crop-out human，而不是继续找完全不可见帧。

### 3. Cell2 不是论文级 hand segmentation

论文使用 hand segmentation periphery 和 object bbox 交集来构造 contact points。E16 仍然使用现有的：

- HOA hand/object bbox；
- skin mask；
- visible object mask；
- object boundary filter；
- contact points 少于 5 个就失败。

这导致 `Cell2_contact_gmm` 直接损失 22 个样本。只要这个策略不改，100 个 subaction 中最多也只能剩 59 个可继续往后走。

### 4. Cell3/geometry gate 是 hard QA，不是 label generation

论文使用 homography 生成 label，但 E16 把很多几何指标作为硬筛选条件：

- pairwise good matches；
- inliers；
- inlier ratio；
- projected object polygon valid；
- contact near object；
- trajectory in bounds；
- contact points in bounds。

这些 gate 对做高质量诊断有价值，但会进一步降低数据量。

## 七、结论

E16 证明了一个重要判断：

> E15 的 strict global no-hand reference 确实过严，active-hand-invisible reference 更接近论文可用语义。

但是 E16 也证明：

> 只改 reference 不可能达到 80/100，因为当前 pipeline 在 Cell2 之后理论上限只有 59/100。

如果目标是接近论文级数据量，下一步不能继续只调 reference。需要新开 E17，方向应从“严格审计单个 subaction”转向“论文式数据挖掘”：

1. 不把 EPIC annotation subaction 当硬 sequence 边界；
2. 对 continuation contact 回溯真实 first contact；
3. 加入 human crop-out reference fallback；
4. 放宽或重写 Cell2 contact point extraction；
5. 区分 `label_generated` 和 `high_quality_geometry_pass` 两套成功指标。

E16 的定位因此是：

> E16 是 active-hand-invisible reference baseline，用来证明 reference 语义从 strict global no-hand 放宽后确实显著改善，但它仍不是论文级 high-volume data mining pipeline。

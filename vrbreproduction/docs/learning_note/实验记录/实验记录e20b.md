# e20-b 2026-7-8

## 一、E20-B 实验设计思路

E20-B 是针对 E20-A 六类质量问题的修复版。E20-A 证明了 SU 同款 GPU 流程能跑通（SAM + LaMa + SD + SDEdit），但结果不可用：56 个样本里严格 QC 只有 1 个通过，大量样本手/手臂残留。

E20-B 的目标：

1. 更稳定地识别手和手臂；
2. 避免只 P 掉手掌、留下手臂；
3. inpaint 后看起来像"画面里从来没有出现过手"；
4. 避免 SDEdit/img2img 增强导致全图变糊；
5. 保持 E20/E20-A 两遍式设计（export 几何 → GPU inpaint → 本地重绘标签）；
6. 输出结构与 E20-A 一致，便于对比。

## 二、E20-A 失败原因定位（先分析后改）

| # | 现象 | 根因 |
| --- | --- | --- |
| 1 | 12/56 样本 `hand_box_count=0`，手完全没 P | export 用 HOA 检测 @score≥0.5：其中 8 个样本 ref 帧其实有 0.04–0.32 的低分框；4 个样本 ref 帧完全无检测但 ±1~3 邻帧就有 ≥0.5 的框。MediaPipe fallback 因 0.10.35 无 `mp.solutions` API 静默失败 |
| 2 | 只 P 手掌留手臂（如 subaction_29） | SAM box prompt 只分割手掌；trapezoid 延伸只向下、宽度 1.2×，斜向/更宽的手臂盖不住；HOA 本来就只标手不标臂 |
| 3 | P 得奇怪（如 subaction_32） | mask 边界切断手臂 → LaMa/SD 以边界残留皮肤为上下文，把手臂"补回来"。40/56 样本 LaMa 后 mask 内肤色 >0.3 |
| 4 | 不自然、像修补过 | 同 2/3：mask 不完整是主因 |
| 5 | SDEdit 全图变糊（如 subaction_88） | 全图 456×256 低分辨率过 VAE roundtrip（strength=0.1 也挡不住 VAE 细节损失），且没有 mask 内合成 |
| 6 | QC 失真 | `boundary_delta` 恒为 0（度量 mask 外环带，而 composite 保证外部逐像素不变——指标无效）；YCrCb 肤色范围把木质台面/地板也算皮肤（实测 subaction_88 全图 61.7% 像素同时通过 YCrCb+HSV 肤色规则），QC 大面积误报 |

一个重要的失败尝试（记录在案）：先试了"肤色连通域生长"来覆盖手臂，本地验证发现 EPIC 厨房的木质台面/地板与皮肤在 YCrCb 和 HSV 里完全不可分（生长后 mask 面积 0.86），**颜色方法在这个数据集上是死路**，必须用语义检测。

## 三、E20-B 相对 E20-A 的改动

### 检测（修问题 1）

- pack 阶段从 HOA pkl 导出三层 boxes：
  - `hand_bboxes_px`：ref 帧 @0.5（原版）；
  - `hand_bboxes_low_px`：ref 帧 @0.1（救回 6 个样本）；
  - `neighbor_hand_bboxes_px`：±6 邻帧 @0.5 每侧最近一帧（救回 6 个样本，box 外扩 12px 补偿手部移动）；
- GPU 阶段新增 **GroundingDINO**（`IDEA-Research/grounding-dino-tiny`，transformers 内置）文本提示 `"a human hand. a human arm."` @0.30——手臂本来就没有 HOA 框，这是 E20-B 最大的 box 来源（83 个）；
- 低分/邻帧 box 有肤色证据 gate（≥0.05，防"鬼框"圈到目标物体）；面积 >70% 的框丢弃；IoU≥0.55 去重。

### Mask（修问题 2/3/4）

- SAM per-box（同 E20-A）→ 方向感知的 `bridge_components_to_border`（不再只向下延伸，向最近的上/下/左/右边界架桥，宽度 1.4×/远端 1.5×）→ `fill_mask_holes`（表带洞）→ close(9) → dilate(14)；
- mask 面积 build 上限 0.55，超限退回紧致版本（QC pass 门限放宽到 0.65，大手臂样本 mask 本来就该大）。

### 残留复检重画（修问题 3/4）

- LaMa 后用 DINO 在结果上重检测（@0.25，只看 mask 邻域 24px 内的框）；若仍有 ≥0.35 的手/臂框，SAM 分割这些框并入 mask 再重画，最多 3 轮；SD 复用收敛后的 mask。46 个样本 1 轮收敛，10 个用了 2 轮。

### SD inpaint（修问题 4）

- 弃用 512 letterbox（replicate 边带污染上下文），改为 2× 原生宽高比（912×512）推理后 INTER_AREA 降采样回帖；steps 30→40；
- prompt 改为 "an empty kitchen counter, clean background..."，negative 增加 "new object, extra object, blurry, deformed"。

### SDEdit 增强（修问题 5）

- 2× 上采样后 img2img（strength 0.15, steps 30），降采样回原尺寸后 **只在 dilate(mask,6) 内 feather=5 合成**——mask 外逐像素与底图一致，全图模糊问题从机制上消除；
- 增强图仍只作候选（sdedit_lama/sdedit_sd），不作 final。

### QC 与 final 选择（修问题 6）

- 废掉恒为 0 的 `boundary_delta`，字段改存 seam gradient ratio（mask 边界带梯度能量 edited/original，≤1 说明接缝不比原手边缘更扎眼）；
- 核心 QC 换成 **DINO 重检测分数**：`passed = mask外逐像素一致 AND (redetect<0.35 OR redetect≤0.55×原图基线) AND mask面积≤0.65`；
- final 不再 seeded 50/50 随机，改为确定性质量排序：(passed, redetect 按 0.1 分桶, seam ratio, LaMa 优先)——近平局时偏向 LaMa（纹理延续），SD 只在明显更干净时胜出。

## 八、踩坑和修正

1. **肤色生长是死路**：EPIC 厨房木质台面 61.7% 像素同时通过 YCrCb+HSV 肤色规则，颜色无法区分手臂和木头；必须换 GroundingDINO 语义检测。相关 helpers 留在 inpaint_utils 里备查但 worker 不再使用。
2. **pyarrow CXXABI**：transformers→sklearn→pyarrow 在系统 libstdc++ 下崩溃；`LD_LIBRARY_PATH=/opt/anaconda/lib` 解决。
3. **grounding-dino 权重下载**：hf-mirror 对该 repo 的 LFS 重定向到 cas-bridge.xethub.hf.co，服务器侧只有 ~30KB/min；改为本地下载（1 分钟）后上传。
4. **诡异的"传输损坏"**：上传后 sha256 反复不一致、甚至同文件两次 sha256 不同——最终发现是第 3 条里残留的后台 `wget -c -O model.safetensors` 一直在覆写同名文件。杀掉进程后 64MB 分块+逐块 md5 重传一次成功。教训：**放弃某次远端下载时必须确认进程真的被 kill**（此前一条复合命令因 ssh 早退根本没执行 pkill）。
5. **SmoothCloud ssh 常返回 255 但命令实际成功**（E20-A 已知），一律以文件/日志/哈希为准。
6. DINO 重检测在裤腿、膝盖、水管等处有 0.35–0.45 的误报，是 3 个 QC fail 的来源；pass 判据里加入了"相对原图基线降 45%"的备选路径缓解，但没有完全消除。

## 九、结论与 E20-C 建议

1. E20-B 达成主要目标：56/56 全部有非空 mask 和生成 final，严格 QC 通过 1→53，12 个漏检样本全部救回，手臂残留类失败在 contact sheet 上未再观察到。
2. 质量瓶颈从"mask 盖不住"转移到两处：
   - **SD 幻觉**：SD inpaint 在大洞里偏爱生成新物体（盘子/食物），rank 已倾向 LaMa（46/10），但个别样本（如 subaction_08 final=sd）仍选中带幻觉的 SD；
   - **大面积 LaMa fill 的涂抹感**（subaction_08/09 类大洞）。
3. 若做 E20-C，建议：
   - 用重检测分数+人工在新 chart 上抽查，把 rank 的 SD/LaMa 选择改为可人工覆写（manifest 加 override 列）；
   - 大洞样本用 "LaMa 打底 + SD inpaint 局部 refine" 两段式替代单一 backend；
   - 换 EgoHOS 或 hand-object detector 做重检测器，消除裤腿/膝盖误报，把 QC pass 做实；
   - SD 换 inpaint 专用更强模型（SD2-inpainting 权重想办法离线上传，或 SDXL-inpaint），负向提示继续压幻觉。

# e20-c 2026-7-8

## 一、E20-C 实验设计思路

E20-C 是针对 E20-B 四类遗留问题的修复版。E20-B 解决了"mask 盖不住手/臂"（56/56 非空 mask，严格 QC 1→53），但引入/暴露了新的质量瓶颈：

1. **最严重：mask 吞掉目标物体**。统计全部 56 个样本的 qc.json：`overlap_heatmap_top >= 0.99` 的有 **20 个**，`>= 0.5` 的有 35 个。点名样本 subaction_01（open rucksack，黑包被 P 掉）、subaction_66（move cutting board，砧板被 P 掉）只是冰山一角。标签重绘后 heatmap/trajectory 指向空地板，**语义错误，样本不可用**；
2. SD 幻觉花纹进入 final（subaction_08：SD 在大洞里生成文字花纹，而该样本 lama.png 更干净）;
3. 大洞 LaMa 整片涂抹变形（subaction_17：mask 面积 0.50）；
4. QC 重检测（DINO "hand/arm"）在裤腿、膝盖、水管上 0.35–0.45 误报，3 个实际干净的样本被误标 QC fail。

## 二、根因定位（先分析后改）

### 问题 1 的根因链

- 手经常正握着目标物体 → HOA/DINO 手框本身就含物体（sub_66 的手框套住砧板上的手+土豆）;
- SAM box prompt 分割"框内最显著物"→ 直接把物体分出来；
- `bridge_components_to_border` + `dilate(14)` + DINO 重检测多轮扩 mask 把剩余缝隙全部闭合。
- E20-B worker 拿 `heatmap_top_bbox_px`/`crop_bbox_150` 只算统计（`overlap_heatmap_top`），**从未用于约束 mask**。

验证：56 样本中 heatmap 核心 bbox 与手框重叠 >0.5 的有 21 个，与 overlap 高值样本几乎一一对应。

### 问题 2 的可分度校准（本地全量校准，不上 GPU）

用 mask 内 Laplacian 方差比 `sharpness(edited)/sharpness(original)` 在 E20-B 全部 56 样本上校准：

- 所有目视有幻觉的 SD final（含 sub_08 文字花纹）比值 **> 2.0**（2.4–20）；
- 所有干净的 SD final 比值 ≤ 1.95；所有 LaMa 结果 < 1.0（LaMa 只会变糊不会造新纹理）。

阈值 2.0 可完美分离，遂做成 SD 幻觉 gate。注意分母必须是**原图** mask 内 sharpness（E20-B 存的 `sharpness` 只有 edited 值，`sdedit_sharpness_ratio` 是 enhanced/edited，都不可用）。

### 问题 3/4

- 问题 3：mask 过度扩张来自 dilate(14) + 架桥 1.4×（对小手样本偏激进）+ 大 DINO 框（sub_17 一个 0.3+ 面积的 "arm" 误框把冰柜门圈进 mask）；
- 问题 4：DINO 对"细长皮肤色物体"语义泛化（裤腿/膝盖/水管），单靠阈值不可分；但这些误报框内**双规则肤色比例低**，肤色可做"与"条件（绝不能单独用——e20b 踩坑 1：EPIC 木质台面 61.7% 像素通过肤色规则）。

## 三、E20-C 相对 E20-B 的改动

### 1. 标签区域保护（修问题 1，核心改动）

- pack_c 在 tasks.json 里新增 `contact_points_px` / `contact_anchor_xy`（从 labels.json 取，与 E18B 严格同源）；
- worker 新增 `build_protect_mask`：
  - `heatmap_top_bbox_px` 矩形（pad 2px）+ contact point 圆盘（r=6）+ anchor 圆盘为底；
  - 用 SAM 以 heatmap bbox 为 prompt 做**物体分割**（multimask 3 候选），接受条件：面积 ≤0.30、盖住 bbox ≥50%、与手 SAM mask 交集 ≤60%（防 SAM 咬到握物的手）→ 尽量保护整个物体而非仅 bbox；
  - `subtract_protect` 把保护区从 inpaint mask 中硬减掉，**初始 mask 和每轮重画扩 mask 后都执行**；
- qc.json 新增 `protect_source`（bbox / sam+bbox）、`protect_area_ratio`、`protect_conflict_frac`（保护区被原始 mask 覆盖比例，即手-物贴合度）、`protect_intact_final`、`overlap_heatmap_top_raw`（保护前）与 `overlap_heatmap_top`（保护后）；
- 手贴物策略：保护优先。手与物体重叠的像素**不 P**（残手贴物 + 标签正确 > 无手 + 标签指向幻觉地板），此类样本由 `label_region_conflict=true` 标记、QC 如实 fail，属"设计内残留"。

### 2. SD 幻觉 gate（修问题 2）

- `sharpness_ratio_vs_original > 2.0` 或 `mask_area_ratio > 0.40`（大洞禁 SD）→ `sd_final_eligible=false`；
- rank 键序：**幻觉 gate > passed > redetect 分桶 > seam > LaMa 优先**。第一轮跑完发现 gate 排在 passed 之后时，5 个样本（08/09/10/12/14）里"有幻觉但重检测干净的 SD"仍胜过"纹理干净但重检测报手的 LaMa"，遂把 gate 提到最前重跑（第二轮）。

### 3. 更克制的 mask（修问题 3）

- dilate 14→8、架桥宽度 1.4→1.3、重画扩 mask dilate 12→10、cap 回退 dilate 10→6；
- 大 DINO 框（>0.30 帧面积）需肤色证据 ≥0.03 才接受（sub_17 的冰柜门误框被这条挡掉）；
- SDEdit 合成区改为 dilate(mask,4)−protect（原 6，且不再碰保护区）。

### 4. 肤色确认的重检测（修问题 4）

- `redetect_hands` 对每个 DINO 框加 `skin_ratio_in_bbox >= 0.10` 的"与"条件（qc.json 同时保留 `redetect_raw_*` 未确认分数备查）；
- 裤腿/膝盖/水管误报框肤色不足被过滤，E20-B 的 3 个误伤样本（06/09/17）中 09/17 转 PASS（06 仍 fail 但原因变为真实的手-物贴合残留）。

- 大 DINO 框肤色 gate 生效（`dino_skin_dropped` 计数）；重检测肤色确认后 E20-B 的裤腿/膝盖类误报未再出现在 fail 原因里；

## 八、踩坑和修正

1. **rank 键序 bug（第一轮全量重跑的原因）**：幻觉 gate 最初排在 `passed` 之后，导致"SD 有幻觉但重检测干净（passed=true）"仍胜过"LaMa 干净但重检测报手（passed=false）"，5 个样本（08/09/10/12/14）final 仍是幻觉 SD。gate 必须排 rank 第一键——幻觉是语义级错误，比重检测残留严重。改后重跑整轮（GPU 便宜，328s）。
2. **E20-B 的 qc.json 无法直接校准"vs 原图"的幻觉指标**：它只存了 edited 的 sharpness。校准脚本必须本地重新读原图+mask 算分母。E20-C 已把 `sharpness_ratio_vs_original` 写进 qc.json，下轮迭代不用再补算。
3. **SAM 物体分割会咬到握物的手**：heatmap bbox 为 prompt 时，SAM 多 mask 候选中常有一个把手也包进来。必须用"与手 SAM mask 交集 ≤60%"过滤，否则保护区反而把手也保护住，手 P 不掉。31/56 个样本三个候选全被拒（物体太大/太小或与手粘连），退回 bbox 矩形兜底——bbox 兜底已足以保证 overlap_heatmap_top=0。
4. **肤色只能做"与"条件**（重申 e20b 踩坑 1）：重检测肤色确认阈值 0.10 用 dual_skin（YCrCb∩HSV）而非单 YCrCb，否则木质台面上的 DINO 框全部通过确认，gate 失效。
5. SmoothCloud ssh 依旧常返回 255 但命令实际成功；两轮 GPU 结果都以 sha256 校验为准。

## 九、结论与 E20-D 建议

1. E20-C 达成核心目标：**目标物体零吞噬**（56/56 overlap_heatmap_top=0，protect_intact 56/56），SD 幻觉不再进 final（gate 拦 23 个），大洞扭曲（sub_17 类）消除，QC 误报（裤腿/膝盖）清除；真正可用样本 tier A 16→38。
2. 质量瓶颈转移到**手-物贴合样本**（28 个 conflict，其中 14 个 QC fail）：保护约束下贴物的手指/手掌残留。这是当前设计的 hard case——保护和去手在像素级冲突。
3. 若做 E20-D，建议：
   - **精细手-物分离**：用 EgoHOS（egocentric hand-object segmentation）替代 SAM box 分割，直接输出 hand / object / interaction 三类像素级 mask，把"减掉整个保护区"改成"只减物体像素"，贴物残手可以再 P 掉一圈；
   - 对 14 个 conflict-fail 样本做 per-pixel 顺序 inpaint：先 P 手（物体像素冻结），LaMa 用物体边缘做上下文，观察边缘贴合质量；
   - 08/09/10 类大臂洞可试 "LaMa 打底 + SD 仅在洞心 refine" 两段式（E20-B 结论遗留项，本轮未做）；
   - manifest 加人工 override 列（E20-B 建议保留）。

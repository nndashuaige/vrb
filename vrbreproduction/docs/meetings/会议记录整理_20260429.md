# 会议记录整理

> 整理自语音逐字稿，已按 VRB 项目术语订正语音识别错误。

## 背景
准备开始大批量生成训练数据。但启动批量生成前，还有几个之前没处理好的问题必须先确认。

---

## 一、heatmap 检查（最高优先级）
- 之前 heatmap（原文"k的map"）的分布看起来不太对，但不太确定，**需要再次确认分布是否正确**
- 模型预测了 **5 个点**，去看 VRB repo（原文"posture / VRB report"）里有没有可视化脚本
- 按 VRB repo 里的方法把这 5 个点可视化出来，看能可视化成什么样子
- 关键动作：check VRB repo, see if there are any visualization scripts

## 二、训练数据格式必须先搞清楚
为后续训练做准备，必须确认数据格式：

- **输入**：1 张图片
- **ground truth 是什么**？要看清楚：
  - 是 5 个 coordinates？
  - 还是 heatmap？
  - 还是 coordinates + 方差（variance）+ 可信度（confidence）？
- 网络输出要和 ground truth 对比来算 loss
- **必须先弄清楚数据形式**，不然自己生成的数据后续没法用，白做

## 三、trajectory 相关疑问
- 5 个点中**有没有起始点**？还是只有 5 个独立的 waypoint？
- 如果模型只输出 5 个点，那自己生成的数据集**也只生成 5 个点**就够了

## 四、数据集生成（少量先验证格式）
- 第一次生成不要太多，**先做 50 个或 100 个**
- 重点先验证格式对不对（第一次做格式很容易出问题）
- 量级目标：50 个左右
- 老师强调："格式要对，不然你生成出来了，自己根本后续没法用"

## 五、任务优先级
| 优先级 | 任务 | 说明 |
|---|---|---|
| **1（最高）** | **heatmap** | 老师明确"我把它移到上面" |
| **2** | **contact point coordinate**（接触点坐标） | |
| **较低 / optional** | 语义提取 + 视频里有手的处理 | "这两个优先级不是那么高，然后是optional" |

- 三个核心任务（原文"三个人"应为"三个任务"）从 1 到 3：
  - 1 = heatmap
  - 2 = contact point coordinate
  - 3 = trajectory + annotation（关键是让数据"变得好看"）
- 视频里"还有手"的情况 → **暂时先别管**，先把 1 和 2 完成

## 六、语义信息提取（不急）
- 长视频里有详细的 annotation，描述每个步骤在干什么
- 想办法从详细描述中提取**短一点的动词短语**
  - 例如："cut 这个东西" → 提取 "cut"
  - "拉" → 提取 "拉"
- **不需要做得很详细**
- 老师可能有更简单的方法，**先不急做这个，之后再讨论**
- 但要时刻记得：**最终要把语义信息加进网络**

## 七、50 个样本必须包含的字段
对每个样本：
- 图片
- heatmap
- contact point coordinate（接触点位置）
- trajectory（轨迹）
- annotation（这是在做什么任务的描述）
